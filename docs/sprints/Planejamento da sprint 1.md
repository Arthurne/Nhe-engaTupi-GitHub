# Planejamento da sprint 1

Status: Pronto
Tempo previsto: 30 min

- Cada membro da equipe deve elaborar RSDs para **DUAS** User Stories.
- Cada User Story pode ter uma ou mais RSDs (`RSD = telas, dados, critérios de aceitação`).
  - Se a User Story tiver mais de uma tela, gera mais de uma RSD.
- **OBS:** Os critérios de aceitação mantêm padrão único e consistente para todo o projeto.
- Relacionar cada história funcional às User Stories Éticas (`UE01–UE25`), verificando acessibilidade, privacidade e fontes culturais.
