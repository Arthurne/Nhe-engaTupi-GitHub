## Convenções de organização

- Os documentos de referência ficam nas pastas temáticas correspondentes.
- Os arquivos CSV da exportação são mantidos em `indices/` como índices auxiliares.
- As atas, modelos e documentos de sprint são preservados.
- A versão anterior do backlog permanece como histórico; a versão de referência atual é identificada nos documentos de requisitos.
- Não se deve inferir implementação, execução de testes, pesquisa real ou aprovação formal sem evidência documental.

## Preservação dos arquivos exportados

Os arquivos exportados do Notion são mantidos como artefatos do projeto. Este índice funciona como ponto de entrada para a documentação, sem substituir o conteúdo original dos documentos.
